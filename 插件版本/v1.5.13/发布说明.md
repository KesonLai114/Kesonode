# Kesonode 1.5.13 发布说明

发布日期：2026-11-10
构建类型：**source（固定扩展 ID，不含 Kesonode 自带 Google OAuth 密钥）**
适用：Chrome / Edge / Brave 等 Chromium 浏览器，以及 Firefox 系浏览器

> 安装与升级步骤见同目录 `安装说明.md`。本文件只讲这一版改了什么。

## 本版包含的内容

本版把两个已提交但尚未打包的特性合并发布：

- **安装后引导（onboarding）体验评审落地**（提交 `e795ed9`）
- **同步 / 备份审查 P1 建议全部落地**（提交 `3f1c1a4`）

## 引导页（onboarding）

- **入口三态守卫**：已配置完成的用户重开 `onboarding.html` 不再用默认值覆盖已有的
  `backends` / `enabled_types` / `active_backend`。入口按 `?reason=` 分为
  setup / update(permissions) / manage 三态；已配置用户进入只读摘要页，可一键「重新配置」。
- **权限人话映射**：原来直接打印 `history` / `tabs` / `management` 与
  `https://host/*`，现在通过 `describePermission()` 给出可理解的中文用途说明；
  未知权限回退到原始标识符（tooltip 仍保留 id）。
- **零类型校验**：数据类型一步若全部关闭，则禁用「继续」并提示，避免同步随后必然报错；
  `finish()` 兜底退回该步。
- **移动端适配**：卡片内边距移到 CSS、新增 520px 断点；进度条从 `position:fixed`
  改为流式，并显示「第 n 步，共 m 步」与「稍后继续」。完成页按类型显示累计同步数量，
  并增加第二台设备的引导。
- 首帧不再先闪一下 welcome 第一步（更新模式与草稿恢复直接落正确步骤）。

## 同步 / 备份（P1 修复）

- **失败退避**：同类同步失败（以错误文案判定）首次不暂停，之后按 2 / 4 / 8 / 15 分钟
  指数退避；本轮成功、force 或 `updateSettings` 时清零。限流不再重复计数。
- **还原点双环形**：手动还原点使用独立的 10 个滚动槽位，与事故自动点分开，互不覆盖。
- **索引条件写**：`getFileVersion` / `putFileIfVersion` 在新版三端后端（WebDAV / GitHub /
  Drive）走 ETag / SHA / If-Match 条件写，减少并发覆盖风险（3 次条件重试 + 1 次无条件兜底）。
- **事故点复用连接**：记录事故还原点时复用 `sync()` 已建立的连接，不再额外 `connect()`
  （限流窗口里最易失败的那次）。手动 / 自动还原点来源标记已修正。
- **凭据提示**：设置导出确认框改为复用 `opt_export_credentials_warning`（8 语言），
  `PRIVACY.md` 新增「Settings backup」一节说明导出文件含明文凭据。

## 升级提示

自 1.5.3 起安装包已固定扩展 ID：**务必把新版解压到全新的 `v1.5.13/` 文件夹**，
移除旧版后用新文件夹「加载已解压」。请勿覆盖解压到旧文件夹（chunk 文件名带内容哈希，
混放会导致 `Unexpected token 'export'` 或设置页空白）。首次换文件夹后，在选项页
「高级 → 导入配置」选此前导出的 `kesonode-settings-*.json` 即可恢复账号与口令。
