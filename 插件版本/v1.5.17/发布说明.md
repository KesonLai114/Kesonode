# Kesonode 1.5.17 发布说明

发布日期：2026-11-12
构建类型：**source（固定扩展 ID，不含 Kesonode 自带 Google OAuth 密钥）**
适用：Chrome / Edge / Brave 等 Chromium 浏览器，以及 Firefox 系浏览器

> 安装与升级步骤见同目录 `安装说明.md`。本文件只讲这一版改了什么。
> 上一次发布是 1.5.16，本版只改了设置页的「导入配置」流程。

## 本版内容

- **导入配置不再在活动日志里留下一条无法避免的手势失败警告**
- 缺少 WebDAV 站点权限时，设置页直接显示带「授权」按钮的授权行，点击时才申请

## 导入配置

导入配置时要先读文件、回答覆盖问题、确认风险；走到最后那一步时，最初那次点击的
「用户手势」已经用完。旧版在这之后才去申请 WebDAV 站点权限，浏览器只能拒绝
（"This function must be called during a user gesture"），这句失败还被写进
「设置 → 活动」，看起来像用户拒绝了某个权限，实际上什么都没发生。

现在导入结束后只读取**当前已经持有的**权限：

- 已经持有 → 不显示任何提示，导入照常完成，并立即开始一轮同步
- 还没有 → 在导入行下方显示授权行（写明是哪个域名）和「授权」按钮；
  点这个按钮时手势是真实的，申请可以成功

这只影响权限申请与提示。已安装 1.5.16 的用户导入配置时不会再看到那条误导性的
活动警告；存储配置、同步数据与还原点都没有变化。
