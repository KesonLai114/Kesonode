# Kesonode 插件 · 安装说明书

本文件所在的 `插件版本/` 文件夹，是**所有插件安装包的唯一存放位置**：就在源码文件夹
的根目录里，打开项目一眼就能看到，不用再去 `dist/`、`web-ext-artifacts/` 里翻。

## 新版本怎么放（约定）

每出一个新版本，就在 `插件版本/` 下建一个 `v版本号/` 子文件夹，把该版本的安装包
和一份本说明书一起放进去：

```
插件版本/
├── 安装说明.md                      ← 本文件（通用版，复制到新版本目录里）
├── v1.5.1/
│   ├── kesonode-chrome-1.5.1.zip       Chromium 用
│   ├── kesonode-firefox-1.5.1.zip      Firefox 用
│   └── 安装说明.md                    每个版本都带一份
└── v1.5.2/ ...
```

- 本地安装包由 `npm run package:source` 生成在 `web-ext-artifacts/source/`，复制到对应
  版本目录即可（`.gitignore` 已忽略 zip，不会误提交进仓库）。
- `store` 变体是上传应用商店用的，文件名和 source 版几乎一样、只差几十字节，
  **不要和本地安装包混放**，否则容易拿错。

## 安装前

- 支持 Chrome / Edge / Brave 等 Chromium 浏览器，以及 Firefox 和 Firefox 系浏览器。
- **zip 要先解压**：浏览器加载的是「文件夹」而不是压缩包。解压后打开文件夹，
  应该能直接看到 `manifest.json`，记住这一层的路径。
- 解压后的文件夹不要删、不要移动，浏览器运行期间会一直从这里读取插件。

## Chromium（Chrome / Edge / Brave）

1. 地址栏输入 `chrome://extensions`（Edge 用 `edge://extensions`，Brave 用
   `brave://extensions`）。
2. 打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选中**直接含 `manifest.json`** 的那一层文件夹。
4. 装好后建议把 Kesonode 固定到工具栏，方便随时打开。

## Firefox

1. 地址栏输入 `about:debugging#/runtime/this-firefox`。
2. 点「临时载入附加组件」，选择解压文件夹里的 `manifest.json`。
3. 注意：**临时加载在浏览器重启后会失效**，需要重新载入一次。Kesonode 目前没有
   上架任何扩展商店，也就没有签名版；每次重启浏览器后重新载入一次即可。

## 装好之后（第一次使用）

安装完成后会自动打开设置向导：选存储位置（Google Drive / GitHub / WebDAV）
→ 登录或填写凭据 → 勾选要同步的内容（书签默认开）→ 选择是否开启端到端加密
→ 完成首次同步。之后点工具栏图标看同步状态，在选项页改设置。

多台设备要连**同一个后端、同一个账号**；开了加密就必须用**同一个口令**。口令丢失后
加密数据无法恢复，请存进密码管理器。

## 几个要紧的提醒

- 这里的安装包是不含 Kesonode 自带 Google OAuth 密钥的 `source` 构建：
  **GitHub、WebDAV 开箱即用**；要用 Google Drive，需自己创建 OAuth 客户端
  （`drive.file` 权限），并把 `https://<扩展ID>.chromiumapp.org/gdrive` 加入授权
  重定向 URI。扩展 ID 在 `chrome://extensions` 的插件卡片上可以看到。
- 本地加载的扩展 ID 与商店版不同，商店版已保存的账号授权不会带过来；同步数据本身
  存在你自己的网盘 / GitHub 里，连上同一个后端即可读到。
- 升级新版本：
  - 在**同一个文件夹**里替换了构建产物 → 在扩展页点插件卡片上的 ↻ 刷新即可。
  - 换成**新版本文件夹** → 先移除旧版，再用新文件夹「加载已解压」；本地设置可能
    不保留，请先记好后端账号与加密口令，加载后在向导里重连同一后端。
- 卸载：先在扩展页移除插件，再删除解压出来的文件夹。

## 出问题了

| 现象 | 处理 |
|------|------|
| 提示清单文件无效 / 加载失败 | 选错层级了，要选直接含 `manifest.json` 的那一层 |
| 找不到图标 | 在浏览器工具栏的扩展（拼图）按钮里把 Kesonode 固定 |
| 加载后没反应 | 在扩展页点卡片上的 ↻ 重新加载 |
| Firefox 重启后插件消失 | 临时加载的正常行为，重新载入一次 |
| 同步不动、登录失败、冲突提示 | 见源码根目录 [TROUBLESHOOTING.md](../../TROUBLESHOOTING.md)；完整上手见 [GETTING_STARTED.md](../../GETTING_STARTED.md) |
