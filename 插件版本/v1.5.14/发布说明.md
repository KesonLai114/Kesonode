# Kesonode 1.5.14 发布说明

发布日期：2026-11-10
构建类型：**source（固定扩展 ID，不含 Kesonode 自带 Google OAuth 密钥）**
适用：Chrome / Edge / Brave 等 Chromium 浏览器，以及 Firefox 系浏览器

> 安装与升级步骤见同目录 `安装说明.md`。本文件只讲这一版改了什么。

## 本版包含的内容

- **同步可见性**：设置 → 活动新增常驻状态条与各类型累计（提交 `2d89316`）
- **限流窗口内的三处自激与误导**（提交 `caaefcf`）
- **还原点名字不再自己变**（提交 `bb14d57`）
- **同步 / 存储 / 后端边界修复**：审批预算、条件写索引、标签页判定、
  Drive / GitHub / OAuth（本轮提交 `46b94c2`）

## 同步可见性

- 活动页顶部新增状态条：状态点与状态词、距上次同步（相对时间，悬停显示准确时刻）、
  下次同步（读取 `chrome.alarms` 的真实排期，而非用上次时间推算）、失败时直接显示
  `last_error`。
- 新增各类型累计 chip 行，已关闭的类型压暗但仍保留计数——回答「历史记录为什么一直是 0」。
- 弹窗右上角由 `HH:MM` 改为「3 分钟前」，与设备列表使用同一套相对时间。

## 限流与首次同步

- **审计日志不再被恢复记录挤满**：「Reset stuck syncing state」原来用 `logger.event`
  写入 200 条环形审计日志，限流周期里每分钟一条，会把真正的 403 挤出窗口；现在只写
  console。
- **坚果云 503 判为限流**：窗口耗尽时部分方法回 503 而非 403，原来被报成「检查路径和
  写入权限」且不启动冷却，导致每分钟继续消耗空窗口。其他主机的 5xx 保持原文案，避免
  一次抖动把 NAS 冷却 30 分钟。
- **首次同步「以云端为主」不再先写还原点**：先读 peer，成功后才写还原点再替换；
  下载被拒时按限流启动冷却。「以本机为主」在限流后停止继续删除并说明原因。

## 还原点

- **设备名在创建时冻结**：还原点默认名中的设备半段不再随当前设置重算，改名或导入备份
  不会改写历史还原点（`auto_name` 写入共享索引）。
- **不再静默改写设备名**：`cleanDeviceLabel()` 只在名字确实带有本机短 id 时才剥离浏览器
  后缀，「Macbook · Edge」这类手动名称保持不变；`snapshotIsUnnamed()` 只把含 8 位设备 id
  的名字当作机器生成。
- **共享索引只做条件写**：重试耗尽也绝不无条件覆盖他人注释；只有当本机成功删除文件时
  才从索引移除条目，缓存列表里的缺席不再当作已删除。
- **待改名失败保留重试**：未知失败不再被当成「点已消失」而丢弃，保留意图与保留期保护。
- **移动前读实际文件**：不再用缓存列表判定源文件不存在；上次已复制、只在删除处被拒的
  重试可以继续完成。

## 同步正确性

- **批量删除审批只对领取它的那一轮有效**：审批额度在 `finally` 中清零，并作为参数传给
  书签合并，不再被后续操作沿用。
- **手动「以云端为主」被安全闸拦下时明确报错**：给出被拦数量、总数、上限与百分比，
  冲突卡片保持待处理，不再「看起来已解决、实际什么都没删」。
- **周期同步 alarm 跟随 `auto_sync`**：启动时清理残留 alarm，触发时重读设置。
- **并发保存不丢改动**：设置、同步状态、同步锁统一走 `updateKey` 串行读改写；选项页改
  口令与弹窗断开后端同时发生也不会互相覆盖，备份导入走同一路径。
- **书签导入与恢复重叠**：抑制标记改为计数器，两个操作不再把对方的写入记成用户删除；
  URL 比较统一 canonical 化。
- **会话恢复按 id 确认标签页真的出现**：不再用「总数没涨 2」推断被拦截；单标签会话
  不再误记「无上限」。
- **历史访问时间**：只有错误明确提到 `visitTime` 才关闭支持，其他失败先重试普通写入。

## 存储后端

- **Drive**：列表跟随分页；条件写取响应头中的 ETag；版本化文件写入遇 404 报告为已消失，
  不再重新创建。
- **GitHub**：路径各段与分支名做百分号编码；带 sha 的 422 按真实错误上报，不再当作竞争
  失败重试。
- **OAuth**：会话带代次校验，并发刷新只发一次；显式退出后排队中的自动登录不会把用户
  重新登回去；token 响应永不写日志。

## 升级提示

自 1.5.3 起安装包已固定扩展 ID：**务必把新版解压到全新的 `v1.5.14/` 文件夹**，
移除旧版后用新文件夹「加载已解压」。请勿覆盖解压到旧文件夹（chunk 文件名带内容哈希，
混放会导致 `Unexpected token 'export'` 或设置页空白）。首次换文件夹后，在选项页
「高级 → 导入配置」选此前导出的 `kesonode-settings-*.json` 即可恢复账号与口令。
